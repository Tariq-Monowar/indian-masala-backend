=================================
create order
______________POST
{{_baseUrl}}/api/orders/create

header: {
  - token: User (optional)
}

query: {
}

body: {
  - name: string
  - email: string
  - phone: string
  - order_item: [
      {
        id: string
        quantity: number
      }
    ]
}

note:
  - with token: only order_item required, order created now (no otp)
  - first time (new email, no token): create customer + token + order (no otp)
  - second time (email already exists, no token): save food in redis 10m, send otp 10m
  - then call verify-otp with email + otp to create order
  - order_item id is menu id
  - system sets unit_price and total_price
  - system sets order_number as 0001, 0002, 0003, ...

Response (otp sent): {
  {
    "success": true,
    "message": "OTP sent to your email",
    "otp": null
  }
}

Response: {
  {
    "success": true,
    "message": "Order created successfully"
  }
}

Response (new customer): {
  {
    "success": true,
    "message": "Order created successfully",
    "token": "jwt..."
  }
}

get all orders
______________GET
{{_baseUrl}}/api/orders/get

header: {
  - token: Admin
}

query: {
  - cursor={{id}}
  - limit={{limit}}
  - search={{search}}
  - status={{status,status}}
  - started_date={{YYYY-MM-DD}}
  - end_date={{YYYY-MM-DD}}
  - object_id={{id}}
}

body: {
}

note:
  - send jwt in token header
  - cursor is the last order id from the previous page
  - limit defaults to 20 and max is 50
  - do not send cursor on the first page
  - object_id pins that row first, then other rows
  - strong search: order id, order_number (0001 or 1), name, email, phone (digits too), status, total_price, food name, quantity
  - spaces in search are flexible (tariq chicken matches)
  - status filter: pending, confirmed, preparing, completed, cancelled
  - status=pending,confirmed returns those statuses (case insensitive)
  - started_date and end_date filter createdAt
  - end_date includes that full day

Response: {
  {
    "success": true,
    "data": [
      {
        "id": "uuid",
        "order_number": "0001",
        "name": "Tariq Monowar",
        "email": "tariq@example.com",

        "order": [
          {
            "name": "Butter Chicken",
            "quantity": 2
          }
        ],
        "total_price": 24.5,
        "status": "pending",
        "createdAt": "2026-09-19T10:00:00.000Z"
      }
    ],
    "pagination": {
      "hasMore": false
    }
  }
}
