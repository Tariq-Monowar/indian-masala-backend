=================================
create order
______________POST
{{_baseUrl}}/api/orders/create

header: {
}

query: {
}

body: {
  - name: string
  - email: string
  - phone: string
  - order_item: [
      {
        id: string
        quantity: number
      }
    ]
}

note:
  - public route, no header token needed
  - name, email, phone always from body only
  - response always returns a customer token
  - token payload: name, email, phone, role: customer
  - name, email, phone saved on the order itself
  - order_item id is menu id
  - system sets unit_price and total_price
  - system sets order_number as 0001, 0002, 0003, ...
  - notifies all admin

Response: {
  {
    "success": true,
    "message": "Order created successfully",
    "id": "uuid",
    "order_number": "0001",
    "token": "jwt..."
  }
}

get all orders
______________GET
{{_baseUrl}}/api/orders/get

header: {
  - token: Admin | Customer
}

query: {
  - cursor={{id}}
  - limit={{limit}}
  - search={{search}}
  - email={{email}}
  - order_number={{order_number}}
  - status={{status,status}}
  - started_date={{YYYY-MM-DD}}
  - end_date={{YYYY-MM-DD}}
  - object_id={{id}}
}

body: {
}

note:
  - send jwt in token header
  - customer token: email comes from token, same as ?email={{}}
  - customer sees only their own orders
  - admin can still send ?email={{}}
  - cursor is the last order id from the previous page
  - limit defaults to 20 and max is 50
  - do not send cursor on the first page
  - object_id pins that row first, then other rows
  - email={{}} returns only that customer's orders (order.email, case insensitive)
  - order_number={{}} returns only that order number
  - response includes that customer data: name, email, phone
  - strong search: order id, order_number (0001 or 1), name, email, phone (digits too), status, total_price, food name, quantity
  - spaces in search are flexible (tariq chicken matches)
  - status filter: pending, confirmed, preparing, completed, cancelled
  - status=pending,confirmed returns those statuses (case insensitive)
  - started_date and end_date filter createdAt
  - end_date includes that full day
  - image is menu images[0] filename

Response: {
  {
    "success": true,
    "data": [
      {
        "id": "uuid",
        "order_number": "0001",
        "name": "Tariq Monowar",
        "email": "tariq@example.com",
        "phone": "01712345678",
        "order": [
          {
            "name": "Butter Chicken",
            "quantity": 2,
            "image": "1710000000000-one.jpg"
          }
        ],
        "total_price": 24.5,
        "status": "pending",
        "createdAt": "2026-09-19T10:00:00.000Z"
      }
    ],
    "pagination": {
      "hasMore": false
    }
  }
}

}

=================================
update order status
______________PATCH
{{_baseUrl}}/api/orders/update

header: {
  - token: Admin
}

query: {
}

body: {
  - ids: string[]
  - status: pending | confirmed | preparing | completed | cancelled
}

  - send jwt in token header
  - send one or more order ids
  - status is required

  }
}
