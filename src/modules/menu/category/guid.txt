=================================
create category
______________POST
{{_baseUrl}}/api/menu/category/create

header: {
}

query: {
}

body: {
  - name_en: string
  - name_fr: string
  - icon: string
}

note:
  - name_en and name_fr are required
  - legacy body `name` is accepted only as fallback if name_en/name_fr missing
  - response returns only name_en + name_fr (no legacy `name` field)
  - DB column `name` is synced from name_en for menu.category_name denorm only
  - icon is optional

Response: {
  {
    "success": true,
    "data": {
      "id": "uuid",
      "name_en": "Starters",
      "name_fr": "Entrées",
      "icon": "starter.png",
      "createdAt": "2026-09-12T10:00:00.000Z",
      "updatedAt": "2026-09-12T10:00:00.000Z"
    }
  }
}

=================================
get all category
______________GET
{{_baseUrl}}/api/menu/category/get

header: {
}

query: {
  - cursor={{id}}
  - limit={{limit}}
  - search={{search}}
}

body: {
}

note:
  - cursor is the last category id from the previous page
  - limit defaults to 20
  - do not send cursor on the first page
  - search matches name_en, name_fr, and legacy name

Response: {
  {
    "success": true,
    "data": [
      {
        "id": "uuid",
        "name_en": "Starters",
        "name_fr": "Entrées",
        "icon": "starter.png",
        "createdAt": "2026-09-12T10:00:00.000Z"
      }
    ],
    "pagination": {
      "hasMore": false
    }
  }
}

update category
______________PATCH
{{_baseUrl}}/api/menu/category/update/:id

header: {
}

query: {
}

body: {
  - name_en: string
  - name_fr: string
  - icon: string
}

note:
