=================================
create menu
______________POST
{{_baseUrl}}/api/menu/create

query: {
}

body: {
  - food_name: string
  - category_id: string
  - min_price: number
  - max_price: number
  - preparation_time: number
  - spicy_level: mild | medium | hot
  - description_en: string
  - description_fr: string
  - images: file[]
}

note:
  - Authorization admin token
  - Content-Type is multipart/form-data
  - upload.array("images", 10)
  - all fields are optional
  - category_id copies category name and icon onto the menu
  - images are files, not JSON
  - saved image is filename only

get all menu
______________GET
{{_baseUrl}}/api/menu/get

query: {
  - cursor={{id}}
  - limit={{limit}}
  - search={{search}}
  - category={{category,category}}
  - spicy_level={{level,level}}
  - price={{1,20}}
  - min_price={{1}}
  - max_price={{20}}
  - preparation_time={{1,20}}
  - sort={{asc|desc}}
  - sort_by={{createdAt|price|min_price|max_price|preparation_time}}
}

body: {
}

note:
  - cursor is the last menu id from the previous page
  - limit defaults to 20 and max is 50
  - do not send cursor on the first page
  - search matches food_name, category_name, description_en, description_fr
  - category accepts names or ids, spaces are ok
  - spicy_level is case-insensitive
  - price=1,20 or max_price=1,20 is a dollar range
  - category=Mains&price=1,20 returns that category priced 1 to 20
  - preparation_time is a from,to minute range
  - sort defaults to desc
  - sort_by defaults to createdAt

delete menu bulk
______________DELETE

query: {
}

body: {
  - ids: string[]
}

note:
  - Authorization admin token
  - send one or more menu ids
  - deletes matching menus and their images

    "success": true,
    "message": "Menus deleted successfully"
  }
}
